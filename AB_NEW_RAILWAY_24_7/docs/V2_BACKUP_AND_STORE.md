# V2
- Full owner backup exports every SQLite table dynamically, including future tables.
- Backup embeds static/uploads assets, so store/profile PNG/JPG/WEBP assets travel with the backup.
- Import restores original IDs and relations.
- Store is categorized: avatar, title, frame, badge/crown.
- Owner can continue changing user points from admin.
- Store uploads are designed to be normalized by server to profile-ready assets.
- Domino room creation supports 2, 3, or 4 players.
- Spectator mode is represented in the game UI without revealing private hands.
